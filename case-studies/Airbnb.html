📌 Project Overview

Banele Airbnb is a full-stack clone of Airbnb, built as three connected parts: a public-facing guest site, an admin dashboard for hosts, and a Node.js/Express/MongoDB backend powering both. Guests can browse listings by category and location, view detailed listing pages with an interactive map and live cost calculator, and make reservations. Hosts get a JWT-authenticated dashboard to create, update, and delete listings with real image uploads.

🎯 The Problem

Recreating Airbnb's core booking flow end-to-end — not just the visual layout, but the underlying logic: dynamic pricing that accounts for nights, weekly discounts, cleaning and service fees, and occupancy taxes; location-based search with an accurate map; and a secure, role-aware admin system for managing listings and reservations, all connected to a real database rather than static mock data.

💡 The Solution

I built a three-part application: a React/Vite frontend for guests, a separate React admin dashboard, and a Node/Express/MongoDB REST API connecting both. Listings, users, and reservations are stored in MongoDB via Mongoose schemas, with JWT protecting all admin routes. The frontend integrates Leaflet and OpenStreetMap for interactive, no-API-key location maps, and a live cost calculator that recalculates totals as guests change dates and guest count.

👤 My Role

I was responsible for the full build — planning the three-part architecture, designing and building the UI, implementing the backend API and database schemas, wiring up authentication, debugging production issues, and deploying the finished application to Render.

✨ Key Features

  • Category and location-based listing filtering grids
  • Interactive map engine running keyless on Leaflet and OpenStreetMap
  • Dynamic booking matrix with real-time fee and discount calculations
  • Role-based dashboard security isolating Admin, Host, and Guest operations
