Urban Threads

Firebase E-Commerce Application Case Study

📌 Project Overview

Urban Threads is a responsive online clothing store designed for customers who want to browse and purchase modern streetwear. The application includes product browsing, authentication, shopping-cart management, wishlists, filtering, sorting and theme switching.

HTML5 CSS3 JavaScript Firebase Authentication Cloud Firestore Responsive Design Netlify

🎯 The Problem

Customers need a simple way to discover clothing products, save items they like and manage their shopping cart. The challenge was to create a complete e-commerce experience without using a traditional custom backend server.

💡 The Solution

I built a responsive multi-page online store and used Firebase to manage authentication and application data. Customers can create accounts, log in, browse products, search and filter the catalogue, manage a wishlist and update their shopping cart.

👤 My Role

I was responsible for planning, designing, developing, testing and deploying the application. I created the user interface, connected the project to Firebase and implemented the main shopping features using JavaScript.

✨ Key Features

  • User registration, login and logout
  • Firebase Authentication and persistent user sessions
  • Products loaded dynamically from Cloud Firestore
  • Product search, category filters and sorting
  • Add-to-cart and remove-from-cart functionality
  • Cart quantity controls and order-total calculation
  • Personal wishlists for authenticated users
  • Light and dark theme switching
  • Newsletter subscription interface
  • Responsive layouts for desktop and mobile devices

🛠️ Development Process

I began by planning the page structure and the information required for products, users, carts and wishlists. I then built the shared navigation and responsive layout before implementing authentication and Firestore integration.

After the main functionality was working, I added filtering, sorting, notifications, theme switching and form validation. I tested each feature before deploying the project to Netlify.

🔥 Firebase Implementation

Firebase Authentication manages account creation, login, logout, password resets and user sessions. Cloud Firestore stores product information and user-specific cart and wishlist data.

Authentication-state listeners allow the interface to react when a user signs in or out. Firestore snapshot listeners keep cart and wishlist information updated without requiring the customer to reload the page.

🧠 Technical Decisions

I used JavaScript modules to separate responsibilities such as authentication, shop functionality, cart management, wishlists, navigation and theme switching. This made the application easier to understand, maintain and debug.

Firebase was selected because it provided authentication and database services without requiring a separate backend server.

⚠️ Challenges and Solutions

  • Product images initially failed because the Firestore image paths did not match the actual file extensions. I corrected the stored paths and file names.
  • The category filter originally continued showing all products. I updated the filtering logic so the product list is recalculated whenever the category changes.
  • Cart and wishlist data needed to remain connected to the correct user. I used Firebase user IDs to keep each customer’s data separate.
  • Authentication errors were difficult for users to understand. I added clearer feedback messages, form validation and button-loading states.

🧪 Testing

I manually tested account registration, login, logout, password reset, product loading, searching, filtering, sorting, wishlist management and cart calculations.

I also tested the application at different screen sizes to confirm that the navigation, product cards, forms and cart layout remained usable on mobile devices.

📈 Project Outcome

The final result is a deployed and responsive e-commerce application that demonstrates my ability to build user-facing interfaces, work with Firebase services, manage application data and deliver a complete project from planning to deployment.
